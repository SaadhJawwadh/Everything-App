
### 🌟 What's New
- **Tamper-Proof Encrypted Backups (v3)**: Encrypted backups now include automatic integrity verification so corrupted or modified backup files are detected safely before restore, while older v2 backups remain fully supported.
- **Reliable Two-Way Offline Sync**: Offline device-to-device mailbox sync now automatically returns updates in both directions and only marks synced snapshots as processed after your data merges safely.

### 🚀 Improvements
- **Expanded Multilingual Support**: Translated Sync, Backup, and Finance Settings screens across all 8 supported languages, including Tamil, German, Spanish, French, Portuguese, Russian, and Chinese.
- **Faster Background Mailbox Sync**: Offline sync now finishes immediately once pending updates are received instead of waiting for extra timeouts.

### 🐛 Fixes
- **Smooth Backup & CSV Sharing with App Lock**: Fixed an issue where sharing a backup file or CSV export could unexpectedly trigger the App Lock screen when returning to the app.
- **Crash-Safe Sync Retries**: Prevented interrupted offline sync merges from dropping pending device updates on the next sync attempt.
