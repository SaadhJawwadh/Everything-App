Four focused tools in one encrypted vault

Built for people who want their notes, money, and personal health logs to stay fast and private without monthly subscriptions.

Rich notes and Story Cards

Format checklists, blockquotes, and tables in a lossless Quill editor. Extract text from photos with offline OCR and export multi-slide Story Cards.

Dual-account financial ledger

Separate daily operating spend from savings vaults. Auto-import bank SMS alerts locally, track category budgets, and simplify group Split Bills.

Discreet cycle and health log

Predict upcoming cycles and fertile windows using outlier-aware local math, paired with customizable discreet notifications and optional period notes.

Adaptive Material You widgets

Pin Tasks and Finances home widgets that scale from compact 4x1 strips to tablet layouts, automatically masking balances when App Lock is active.

Direct Wi-Fi sync and desktop browser companion

Pair devices over local Wi-Fi using a 6-digit code and AES-256 encrypted payloads. Open your phone's IP in any desktop browser on port 8765 to browse unlocked notes or download a verified backup.

Primary phone Port 8765 HTTP + UDP beacon 8766

Security you can verify locally

Every record stays on hardware you control, encrypted at rest with SQLCipher and protected by biometric or PIN app locks.

Hardware-backed key storage

Database encryption keys live inside Android Keystore and iOS Keychain rather than plaintext preferences.

Tamper-proof v3 backups

Automated and manual JSON backups include integrity verification and rolling pre-migration database snapshots.
